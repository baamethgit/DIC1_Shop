## Réalisé par : 
- Ameth Ba

Ce projet, réalisé avec Django, est une boutique en ligne nommée DIC1Shop.

## Prérequis:
- Python installé
- Installer les dépendances :
  - Le fichier `requirements.txt` contient les modules nécessaires à l'exécution du projet.
  - Pour installer les modules: `pip install -r requirements.txt` (dans le dossier contenant le projet).
- Connexion internet : Bootstrap est utilisé pour les icônes et une partie de la mise en forme, donc une connexion internet est nécessaire.

## Exécuter le projet:
1. Compiler le fichier SCSS en CSS  `sass style.scss style.css`. Cela peut être fait automatiquement en utilisant l'extension VS Code "Live Sass Compiler".
2. Dans le dossier du projet, naviguez jusqu'au dossier `src` et exécutez la commande : `python manage.py runserver`.

## Utilisation :
- À l'arrivée sur la page d'accueil, vous aurez accès à tous les produits disponibles dans la boutique. Vous pouvez filtrer les produits par catégories ou en utilisant la barre de recherche pour trouver plus facilement ce que vous cherchez.
- Pour voir les détails d'un produit, cliquez sur son nom ou son image. Vous serez redirigé vers une page détaillée où vous pourrez consulter des informations supplémentaires sur le produit.
- Pour accéder à certaines fonctionnalités telles que l'ajout de produits au panier, le passage de commandes, et la gestion de votre profil, vous devez vous inscrire ou vous connecter. Cliquez sur l'icône en forme de personne en haut à droite de la page pour vous inscrire si vous êtes un nouvel utilisateur, ou pour vous connecter si vous avez déjà un compte.Cette icone permet aussi d'accéder ou de modifier les infos de votre compte ,si vous étes déja connecté.
